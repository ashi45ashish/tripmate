TravelMate Application Setup Notes
================================

Environment configuration
-------------------------
- Copy `.env.example` to `.env` for local development.
- Fill in your own local secret values in `.env`.
- Never commit `.env` to source control.
- Store production secrets in your hosting provider or secret manager.

Database Setup
--------------
- The project expects database connection values in environment variables.
- Example variables are provided in `.env.example`.
- For local use, configure your own `DATABASE_URL` and/or `MONGODB_URI`.

Sample Data
-----------
- Sample trips are already loaded in the application.
- You can see these trips after logging in.
- More trips can be added through the configured database later.

Authentication
--------------
- User registration and login is working.
- Session management is implemented.
- Set a strong `SESSION_SECRET` in your environment.

Testing the Application
-----------------------
1. Copy `.env.example` to `.env`.
2. Replace the placeholder values with your local secrets.
3. Register or log in to access the main page.
4. Use the search filters at the top.

Next Steps
----------
- Keep all production secrets out of source control.
- Use your deployment platform's secret manager for runtime values.
- Rotate any credentials that were ever committed previously.
