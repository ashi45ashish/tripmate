TravelMate Application Setup Notes
================================

1. Database Setup
----------------
- The application is currently using in-memory storage
- To switch to MongoDB (when ready):
  - Add your MongoDB Atlas connection URL to .env file:
    MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/travelmate

2. Sample Data
-------------
- Sample trips are already loaded in the application
- You can see these trips after logging in:
  - Beach Paradise (Maldives) - $2,500
  - Mountain Adventure (Swiss Alps) - $3,000
  - More trips can be added through the MongoDB database later

3. Search Features
-----------------
The application includes the following search filters:
- Location search (text-based)
- Trip type filter (domestic/international)
- Duration filter (1-3 days, 4-7 days, 8-14 days, 15+ days)
- Price range filter (slider up to $10,000)

4. Authentication
----------------
- User registration and login is working
- Session management is implemented
- Passwords are securely hashed

5. Testing the Application
-------------------------
To test the search functionality:
1. Register/Login to access the main page
2. Use the search filters at the top:
   - Enter a location (e.g., "Maldives" or "Swiss")
   - Select trip type (domestic/international)
   - Choose duration
   - Adjust price range using the slider
3. Click "Search Trips" to see filtered results

6. Next Steps (Future Features)
------------------------------
- Implement MongoDB integration
- Add more search filters (activities, health requirements)
- Add user preferences and personalized recommendations
- Implement trip booking functionality

Note: The application is currently using in-memory storage, which means data will be reset when the server restarts. Once MongoDB is integrated, the data will persist.
